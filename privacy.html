Privacy Policy

Frank Fitness Editor · Last updated October 28, 2026

Frank Fitness Editor is a private tool built and used only by Owen Frank (owenfrank000@gmail.com) to edit his own videos. It is not available to the public.

What it accesses

With Owen's permission, the app accesses Owen's own Google Drive to read raw video clips he uploads to a designated folder and to save the finished, edited videos back to that Drive.

How the data is used

Video files are downloaded temporarily to an automated, private processing job, transcribed and edited, and deleted from that job when it finishes. Transcripts and edit instructions are stored in Owen's private code repository. Nothing is sold, shared with third parties, or used for advertising.

Google user data

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be revoked at any time from the Google Account's Security settings under third-party connections.
